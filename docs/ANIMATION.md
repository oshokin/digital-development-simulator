# Анимация Макса

Шесть кадров бега и три кадра прыжка уже лежат в `dist/assets/sprites/`. Обзор поз — `docs/max-v2-poses.png`. Из старого набора оставлены только `max-9…11`: приседание, удар и поражение. Остальные устаревшие кадры удалены из игрового дистрибутива.

В `dist/js/animation.js` беговой цикл задаётся отдельными ключевыми позами с длительностью и высотой относительно пола. При переходе между кадрами рисуется одна непрозрачная поза: прежнее полупрозрачное наложение удалено. При увеличении скорости частота цикла растёт вместе с темпом дороги.

Прыжок: `max-v2-jump-0` при отрыве, `max-v2-jump-1` в воздухе и `max-v2-jump-2` при посадке. Поза в воздухе не меняется скачком на вершине траектории. Точки привязки стоп для каждого кадра перечислены в `FOOT_ANCHOR`.
