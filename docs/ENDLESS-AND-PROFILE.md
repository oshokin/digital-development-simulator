# Режимы и визитка

Бесконечный забег не переключает уровни и не показывает сюжетные развилки. После поражения он начинается с нуля. Кампания сохраняет пять этапов и две концовки; после поражения можно повторить текущий этап либо всю игру. Фон бесконечного режима — `dist/assets/backgrounds/scene-endless.png`, без повторения краёв изображения.

На визитке пять работ: текущее распределённое объектное хранилище, два проекта под NDA (оценка недвижимости и CRM), xk6-kv и Cursor Chat Transit. Личная информация и имена заказчиков NDA не публикуются. Язык и тема переключаются в закреплённой шапке; `/play/` использует собственную прежнюю шапку.

Проверка: `npm run check`. Локальный запуск: `npm run dev`. Развёртывание описано в `README.md`.
